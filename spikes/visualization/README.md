# Visualization spikes

Small, runnable comparisons using the same `fixtures/small.json` and `fixtures/large.json` (8/8 and 101/105 elements/relationships). These are fixed-fixture prototypes, not a parser, language server, or renderer decision. Run `npm ci` once in this directory.

| Variant | Start | Browser check |
| --- | --- | --- |
| [React Flow + ELK](webview/README.md) | `npm run dev` | `npm run test:browser` |
| [Sprotty + ELK](sprotty/README.md) | `npm run dev:sprotty` | `npm run test:sprotty` |
| [ELK.js + SVG](elk-only/README.md) | `npm run dev:elk-only` | `npm run test:elk-only` |
| [Mermaid.js](mermaid-only/README.md) | `npm run dev:mermaid-only` | `npm run test:mermaid-only` |
| [Dagre](dagre-only/README.md) | `npm run dev:dagre-only` | `npm run test:dagre-only` |

Browser checks require Playwright Chromium. `npm run verify` checks the React Flow package build and unit tests. `npm run fixtures:large` regenerates the stress fixture.

Each variant README records what was checked and its known limits. One or two browser screenshots per variant are kept in `results/`; generated reports, extra screenshots, build output, caches, and `node_modules` are ignored. The React Flow extension packages a webview worker generated by `npm run dev` or `npm run build`.
